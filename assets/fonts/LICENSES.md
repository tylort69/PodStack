# Bundled fonts

- **Inter** (`Inter.ttf`) by Rasmus Andersson — SIL Open Font License 1.1, https://github.com/rsms/inter
- **Material Icons** (`MaterialIcons-400.ttf`) by Google — Apache License 2.0,
  https://github.com/google/material-design-icons

Both were converted from the WOFF2 files the original PodStack shipped (`woff2_decompress`), because HarfBuzz
can't shape WOFF2.
